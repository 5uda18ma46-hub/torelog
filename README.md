# ToreLog

ジムでの記録の手間を最小にすることだけを狙った、個人用の筋トレ記録アプリ。

**https://5uda18ma46-hub.github.io/torelog/**

## できること

- 前回値が入った状態で開き、同じなら1タップで1セット記録
- 種目ごとの重量の刻み（バーベル2.5kg / ダンベル1kg / マシン5kg）とレストタイマー
- レップ上限を超えると警告（1セット目を追い込みすぎないため）
- 全セットが上限に届いたら、次回の重量アップを自動で提案
- 直近7日の部位別セット数、推定1RMと目標ライン、週別の総挙上量、体重、頻度
- 履歴は日付順と種目順の2つの入口から辿れる
- JSONでの書き出しと取り込み

## つくり

- `index.html` 1ファイルのみ。外部ライブラリなし、ビルド不要、オフラインで動作
- 記録は端末の localStorage に保存する。サーバーには何も送らない
- データ構造の仕様は親フォルダの `Resources/データ構造.md` を参照

## 更新のしかた

`index.html` を直して push すると、GitHub Pages に反映される。
